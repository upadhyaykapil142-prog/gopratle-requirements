## Tech Stack

### Frontend
- Next.js
- React
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

### Deployment
- Vercel — Frontend
- Render — Backend
- MongoDB Atlas — Database

## Features

- Multi-step requirement posting form
- Event name and event type selection
- Start and end date validation
- Location and optional venue
- Category selection
- Event Planner requirements
- Performer requirements
- Crew requirements
- Category-specific form fields
- Form validation
- REST API integration
- MongoDB data storage
- Live frontend and backend deployment

## Form Flow

1. Event Basics
2. Category Details
3. Review
4. Submit
